京飞捡漏 · 北京出发低价机票决策工具

一个移动优先的 H5 网页：把「北京出发的实时低价机票」与「法定节假日拼假」「境外目的地证件要求」「飞行与在地时间」结合，帮助价格敏感、假期有限的用户快速判断「这张低价票值不值得请几天假去」。本期只做信息发现与引流，不在站内完成支付出票。

一、要解决的问题

😮‍💨 低价与假期脱节
用户在比价工具里看到便宜票，却要自己翻日历算「要请几天年假、能玩几天」，决策成本高。
🛂 境外门槛不透明
看到境外低价票后，还得另外查签证/免签/落地签与护照要求，信息分散且容易过期，临门一脚被劝退。
⏱️ 时间成本难判断
长途航线「飞多久、到了实际能玩多久」不直观，便宜但耗在路上的票可能并不划算。
📊 信息真伪与时效
低价票时效性强，用户担心看到的是引流噱头或过期价格，需要明确的更新时间与可信跳转。

二、产品目标与非目标

类型内容
产品目标① 让用户在一个页面同时获得「价格 + 拼假天数 + 证件门槛 + 飞行/在地时间」四要素；② 围绕节假日形成可传播的低价专题；③ 以高意向跳转为航司/OTA 引流。
非目标（本期不做）站内支付/出票/退改签、会员登录体系、多出发城市、机酒套餐、价格预测与「再等等」建议、UGC 游记。

三、核心用户与场景

👤 主要用户
常驻北京、22–40 岁、价格敏感且年假有限的上班族/学生；愿意为低价调整出行日期，出境经验深浅不一。
📍 触发时机
节假日前 1–2 个月规划出游；刷到低价信息想快速判断可行性；确定「能请几天假」后反推目的地。
✅ 完成条件
用户对某条线路能回答「请几天假、玩几天、证件行不行、飞去多久」，并点击可信渠道跳转完成比价/下单。

二、关键产品判断

判断理由
做「决策信息」而非「卖票」机票销售涉及资质、资金、出票与退改合规；团队冷启动用引流模式验证「拼假 + 低价」价值，闭环路径在 F-07 预留。
「请假天数」前置到卡片用户最大约束是假期而非价格；卡片层即露出请几天、玩几天，降低点进详情的决策成本。
双板块强切分国内/境外的决策要素不同：境外必须展示证件，国内不展示；混排会造成信息噪音与合规误解。
地图与列表平行而非新数据源地图只改变发现视角（空间 + 约束图层），与列表共用线路、价格时效与筛选，避免两套口径；三图层坚持"一图一主题"，避免多维度叠加造成阅读负担。
时间用「总飞行 + 在地游玩」双指标单一直飞时长不能反映中转与实际游玩窗口；双指标让长航程低价票的性价比可比。
证件信息强调时效与免责签证政策会变化，产品只做信息聚合与核验提示，必须展示更新时间并引导至官方渠道，不承诺过签。
实时数据 + 运营精选并存纯 API 缺乏节假日场景叙事，纯人工覆盖与时效不足；榜单为实时聚合，节假日专题由运营编排并标注。

四、角色与权限

本期无登录，只有匿名访客单一 C 端角色，可浏览、筛选、查看详情、跳转、本地收藏（P1）。运营对「精选线路、假期方案、证件规则」的维护属于后台能力，不在本期 P0 交付，但其产出是前台数据来源，需在规则页定义更新与失效责任。

五、主要恢复路径

  • 价格失效：进入详情时实时报价已无库存 → 展示失效态，提供「同目的地近期其他日期」与重查，而非展示陈旧价格。
  • 无匹配线路：按可请年假天数筛选无结果 → 说明约束过严，建议放宽天数或板块，保留用户已选条件。
  • 证件政策过期/缺失：证件规则超过更新时限或缺失 → 降级为「请出行前查询官方渠道」强提示，不展示可能错误的具体承诺。

F-01 国内 / 境外双板块价格日历

用户价值：不展示「绝对最低价」（第三方缓存价与 OTA 实时价存在 20%~70% 偏差，不能作为可下单价格承诺），而是用未来一个月每日价格的相对趋势帮用户回答「飞这个目的地，哪几天相对便宜」，再引导用户前往 OTA 查询该日实时价并成交。

触发与流程
  1. 进入首页默认定位出发地「北京（PEK/PKX）」，加载低价日历列表，默认展示「国内」板块。
  2. 用户点击「国内 / 境外」分段控件即时切换列表；境外列表的每张卡片必须含证件门槛标签，国内列表不展示证件元素。
  3. 每张线路卡片展示：目的地（中/英文名）、当月最低参考价及对应日期（如「12月5日 最低 ¥532」）、建议请假天数标签、总飞行时间、在地游玩时间；境外卡额外展示证件政策类型。卡片底部标注「价格趋势参考」。
  4. 点击卡片进入 F-06 详情（含「价格日历趋势」面板，列出当月最低/最高与最便宜 3 天）；点击卡片右下角「📅 看价格日历」进入价格日历屏（F-01 子视图），查看整月每日价格热力。
规则与边界
  • 价格口径：来自 Travelpayouts 历史缓存价，仅用于判断「哪天相对便宜」，不展示、不承诺绝对最低价；卡片与详情一律标注「趋势参考，实时价以 OTA 为准」。
  • 列表默认按「当月最低参考价升序」排序；是否支持按飞行时长/请假天数排序列为 P1。
  • 出发地在本期固定北京且不可更改；点击出发地区域给出「更多城市即将开放」的不可用反馈，不出现死按钮。
  • 板块切换不产生跨板块信息：境外证件字段永不出现在国内卡上。
  • 用户最终成交发生在跳转后的 OTA / 航司官网，本产品不碰支付、不出票、不展示可下单的绝对价。
原型对应

首页「📅 低价日历 · 哪天飞最便宜」分段控件（国内/境外）与「列表 / 地图」视图切换；线路卡片显示当月最低参考日与价格，可点进详情或直接「看价格日历」进入整月日历屏。

F-09 低价地图模式（空间发现视图）

用户价值：列表回答"哪个最便宜"，地图回答"世界哪儿有便宜票、这个价要飞多远、签证/请假门槛如何"——把价格、距离、出行约束在同一空间视图里看懂，并和列表共用同一套数据与筛选，两种视图随时切换、口径一致。

入口与视野
  1. 入口位于首页低价榜标题行的「☰ 列表 / 🗺️ 地图」开关；返回即回列表，浏览位置与已选板块保留。
  2. 视野跟随板块自动切换：国内板块 → 中国视野（含海南、台湾等岛屿完整表达，岛屿与大陆同色）；境外板块 → 以北京为中心的世界视野，覆盖东南亚/东亚、中东/欧洲方向。
  3. 地图与列表共用线路数据、价格时效与全部筛选条件（板块、请假天数），只改变呈现，不另造数据。
三个信息图层（一图一主题，可切换）
图层气泡颜色口径帮用户判断
💰 价格热力（默认）同板块内「当月最低参考价」线性归一：绿=更便宜（捡漏）→ 橙 → 红褐=相对较高；失效价灰色哪个区域低价最密集、目的地之间贵多少
🛂 签证门槛（仅境外有差异）绿=免签，蓝=电子签/落地签，紫=需提前办签；国内视野统一灰蓝（身份证即可）能不能"说走就走"，复用 F-04 政策类型，不另立口径
📅 拼假可行选择"最多请几天假"后：预算内目的地蓝色全亮，超预算的变灰半透明按年假预算在地图上"圈定能去的地方"，预算与 F-05 共用同一请假档位
空间元素与交互
  • 北京出发地用红星标注；以其为圆心绘制飞行时间同心圈（世界视野约 3h / 6h / 10h+，中国视野约 2h / 5h），把 F-03 总飞行时间空间化；同心圈为等时示意，不作为精确距离。
  • 每个目的地为"价格气泡"：当月最低参考价直接标注在气泡内，城市名在气泡下方；点按高亮并在地图底部浮出小卡片（城市、价格、请假标签、签证标签、总飞/在地时间、中转），浮卡展开期间临时收起图例/水印避免遮挡，"查看完整详情"进入 F-06；再次点按同一气泡可收起浮卡，切换板块/图层/请假预算时浮卡自动收起。
  • 缩放导致同区域气泡重叠时按区域聚合（如"东南亚 N 城 ¥xxx 起"），聚合阈值与展开方式 [Assumption,TBD]；原型城市较少，直接全量展示。
  • 失效价格（如巴厘岛示例）在地图上同样显示灰色"失效"气泡，点按展示失效小卡并引导替代线路，与 F-08 一致。
底图合规（正式实现必须遵守）：原型为自绘风格化 SVG 示意图（非测绘图，已在图内标注）。正式 H5 须使用具备测绘资质、带审图号的合规底图（境内如高德/腾讯地图 JS SDK，GCJ-02 坐标），由地图引擎投影换算像素；世界地图须正确表达国境线，台湾、南海诸岛等不得缺失或错绘，中国视野岛屿与大陆同色。境内环境不得直连未合规的境外地图服务。
边界
  • 地图不产生列表之外的新价格/新政策；气泡点击热区要适配触屏，气泡过密时优先聚合而非缩小到不可点。
  • 加载中显示底图骨架与气泡淡入；某区域暂无数据不留空白点，以"暂无低价"区域态或不放置气泡处理。
原型对应

首页低价榜标题行「🗺️ 地图」开关 → 低价地图页：可切换国内/境外视野、三个图层、请假预算档位，点按气泡出现小卡并可进详情。

F-02 节假日拼假日历与建议请假天数

用户价值：直接回答「为了这趟旅行要请几天年假、怎么请最划算、能连休几天」。

触发与流程
  1. 首页「假期捡漏」展示最近一个法定节假日的最优拼假方案摘要（法定区间、建议请假日期、请假天数、连休总天数）；点击或底部「假期」Tab 进入拼假日历。
  2. 日历以颜色区分：法定放假日、周末、建议请年假日；顶部可切换各法定节假日。
  3. 系统为每个假期给出至少一个「最优拼假方案」：请假区间、需请假天数、连休总天数，并据此推荐「适合的行程长度（在地游玩天数）」区间。
  4. 日历下方展示「这个假期能去哪儿」：按该连休长度可达成的低价线路（自动套用到 F-01 列表，过滤在地时间适配的线路）。
拼假计算规则（口径见规则页）
  • 最优方案 = 在「请假天数最少」前提下「连休总天数最长」的请假区间；存在并列时优先请与法定假相邻的工作日。
  • 同时提供「不请假（仅法定+周末）」「最少请假」「充分连休」至少三档，让用户按年假余额选择。
  • 线路卡片与详情上的「建议请假 X 天」必须与其可搭乘假期方案一致，不得各算各的。
边界
  • 法定放假安排未官方公布的年度，对应假期标记「安排待公布」，不杜撰具体日期。
  • 调班（周末需上班）的日期需在日历明确标识，避免用户误以为是休息日。
原型对应

首页假期横幅、「拼假日历」整页（切换假期、图例、方案、假期线路）。

F-03 预估飞行总时间与在地游玩时间

用户价值：判断「便宜是否值得耗在路上」，并与拼假天数对齐。

展示与计算
  • 预估总飞行时间：去程与回程所有航段实际飞行时长之和（含经停但不含中转等候）；中转次数单独标注。[Assumption,TBD] 是否把中转等候计入「门到门总耗时」在规则页给出可选口径。
  • 在地游玩时间：去程落地（当地时间）到返程起飞（当地时间）之间扣除首末日建议的交通/恢复缓冲后的可游玩时长，折算为「X 天 Y 晚 / 约 X 个完整白天」。
  • 卡片层展示精简双指标（如「飞 3.5h · 玩 4 天」）；详情页用去返程时间轴展示起降时刻、中转、跨时区与昼夜损失说明。
  • 跨时区/跨日航线必须标注「日期增减」提示，避免用户误算请假区间。
边界
  • 时间均为预估值，基于班期计划时刻，标注「以实际航班时刻为准」；航班时刻未确定（远期）时给区间值而非确定值。
  • 同一目的地存在多路线（直飞/中转）时，默认展示总飞行最短方案，并可在详情查看其他方案的时间差异（P0 至少展示一个备选口径说明）。
原型对应

卡片底部双指标、详情「行程时间」面板与去返程时间轴。

F-04 境外证件要求与核验提醒

用户价值：在被低价打动的同一时刻看清入境门槛，避免到机场才发现证件不符。

触发与展示
  1. 仅境外线路展示。卡片用政策类型标签：免签 / 落地签 / 电子签 eTA / 需提前办签，港澳台标注所需往来证件与签注。
  2. 详情提供证件面板：政策状态、停留时长、护照/证件有效期要求（通常≥6 个月）、所需材料、是否可落地/在线办理、建议预留办理时长、信息更新时间与官方来源链接。
  3. 结合用户行程日期给出倒计时提醒：如「距出行 64 天，电子签约预留 7 天，时间充足」；当剩余天数低于建议办理时长时升级为风险色提示。
口径与免责
  • 默认对象为持中国普通护照、北京口岸出境、短期旅游；其他护照身份/长居/公务出行不适用，面板需声明口径。
  • 产品仅聚合信息，不代办、不承诺过签；政策可能变更，必须有更新时间与「以该国官方/使领馆为准」声明。
  • 规则超过更新时限或缺失 → 降级为通用强提示「出行前请查询官方渠道」，不展示具体免签/落地签承诺（对应恢复路径）。
合规边界：证件信息属于高风险时效信息，错误的「免签」结论可能导致用户滞留。宁可降级提示，不可展示未经核验的具体承诺。
原型对应

境外卡片证件标签、详情「入境证件」面板（免签/电子签两种示例 + 风险倒计时）。

F-10 签证类型指南（按入境门槛浏览目的地）

用户价值：回答「我这本护照现在能去哪」——白本或不想提前办签的用户可直接从免签 / 落地签切入选目的地，而不是先比价再逐个查政策；与 F-04「订票前核证件」互补，本功能把签证前置为发现入口。

入口
  • 首页「🛂 签证类型速查」模块：四列展示各类型下当前在营 / 曾售境外目的地数量（免签、落地签、电子签、提前办签），点模块或右上角「全部政策」进入指南页；不新增底部 Tab。
页面结构与交互
  1. 顶部固定口径声明：中国普通护照 / 北京口岸出境 / 短期旅游 / 政策核验月份，与 F-04 完全一致。
  2. 类型筛选 chips：全部 / ✅ 免签 / 🛬 落地签 / 🪪 电子签·eTA / 📝 需提前办签，每个带目的地数量；默认「全部」。
  3. 按类型分组列目的地：组头给出该类型一句话定义与数量；每条目的国行展示旗帜、城市（中英）、准许停留期、政策核验时间、类型标签与当前含税低价。
  4. 某目的地当前无有效低价（如失效价示例）仍保留在分组内，价格位显示「该低价已失效」，点按进入对应失效详情；不因无票而丢失政策入口。
  5. 点按任意目的国行进入 F-06 详情，复用其「入境证件」面板与 F-07 订票引流，本页不另建政策详情页。
规则与边界
  • 类型枚举、配色、免责与降级口径与 F-04 类型表、F-09 签证图层三处一致，单一数据源；指南只做分组与导航，不独立编写或判定政策。
  • 分组数量由当前线路目录实时计算，不手工维护；仅有政策、暂无可售低价的国家是否纳入（纯政策库 / 白本能去的全部国家）[Assumption,TBD]，原型只含在营或曾售线路。
  • 仅境外；国内持身份证不在本指南。港澳台按 F-04 以「往来证件 + 签注」类型单列，原型暂无样例。
  • 处于待核验 / 缺失状态的政策不进入免签 / 落地签分组的绿色 / 蓝色承诺展示，按 F-04 降级口径置灰并提示查询官方渠道。
原型对应

首页「签证类型速查」模块与实时计数、签证指南页（口径声明、类型筛选、分组定义、目的国行与停留期 / 核验时间、失效态、点按进详情）。

F-05 搜索与「按可请年假天数」筛选

用户价值：用最稀缺的约束——年假——反向圈定可行目的地，而不是先选目的地再算假。

流程
  1. 点击首页搜索框打开发现弹层：支持按城市/国家关键词搜索目的地。
  2. 提供「我最多能请几天假」档位（0 / 1–2 / 3–4 / 5+ 天），选择后系统结合假期方案，筛出所需请假天数不超过该值的线路（纯周末与法定假方案对应 0 天）。
  3. 可叠加板块（国内/境外/不限）；点击查看结果进入结果列表，沿用 F-01 卡片样式并显示筛选条件。
筛选规则与边界
  • 筛选只缩小集合，不改变价格与时间口径；结果为空时进入 F-08 空态并保留已选条件，提供放宽建议。
  • 关键词无匹配时不跳转，就地提示并推荐热门目的地；不提供伪造结果。
  • 请假天数筛选与假期方案共用同一计算结果，保证两处「需要请假天数」一致。
原型对应

首页搜索框 → 发现弹层（关键词 + 请假档位 + 板块）→ 结果页/空态。

F-06 线路详情：价格、报价构成与时间轴

用户价值：在跳转前建立信任并核实关键事实。

面板构成
  • 顶部：目的地、含税起价、价格更新时间、数据来源、运营/实时标识。
  • 拼假：适配的假期方案、建议请假区间与天数、连休总天数（链接 F-02 口径）。
  • 行程时间：去/返程起降时刻、总飞行时间、中转次数、在地游玩时间与跨时区说明（F-03）。
  • 证件（仅境外）：完整证件面板（F-04）。
  • 报价构成：明确「起价」含义——含税、含/不含托运行李、适用日期与余票紧张程度；列出该价格对应的具体去返日期。
状态
  • 默认：正常展示；余票紧张：展示「剩余少量座位」（来自数据源真实状态，不虚构数字）。
  • 价格失效：进入详情若无该价库存，切换失效态（F-08），禁用底部「去订票」并给替代方案。
原型对应

详情整页（国内哈尔滨示例无证件面板；境外大阪/清迈示例含完整面板）。

F-07 第三方渠道引流跳转（不收款）

用户价值：从决策无缝进入可信购买，同时明确本站不参与交易。

流程
  1. 详情底部「去订票」打开渠道选择弹层，列出该线路可用的航司官网/OTA（白名单），标注各渠道类型。
  2. 离站前强提示：价格以渠道实时下单页为准、境外需自备有效证件、行李与退改规则见渠道页。
  3. 选择渠道后携带目的地/日期等参数新开页跳转；站内不出现支付、出票、订单、退改环节。
    4. 边界与信任
    • 渠道须为合作/可信白名单，跳转使用可追踪参数用于归因，但不传递个人敏感信息（本期无登录也无此类信息）。
    • 不对渠道最终价做一致性承诺；若渠道价显著高于展示价，属正常实时波动，文案需预先说明。
    原型对应

    详情底部「去订票」→ 渠道弹层（含免责提示）。原型以 Toast 模拟跳转，不离开页面。

F-08 异常、空态与价格失效恢复

用户价值：在数据不确定时获得诚实反馈和下一步，而不是看到错误或陈旧信息。

状态触发表现与恢复
加载中榜单/详情取数使用骨架卡片，不阻塞页面框架。
空结果请假天数/板块筛选无匹配说明约束过严，提供「放宽天数 / 切换板块 / 查看热门」，保留已选条件。
价格失效详情实时价无库存失效提示 + 禁用订票 + 推荐同目的地近期日期与相似线路。
网络/接口失败数据源不可用页内错误态 + 重试；不使用过期缓存冒充实时价，可降级展示运营精选并标注。

一、拼假与请假天数计算

输入：法定放假集合 H（含调休形成的连续休息）、周末集合 W、候选工作日集合 D 连休区间 = 包含目标假期的最长连续「休息日 + 选中请假日」 需请假天数 L = 为形成该连休区间而额外请掉的工作日数量（不含本来就免费的周末/法定日） 连休总天数 R = 连休区间自然日总数 最优方案 = 先最小化 L，再最大化 R；并列时优先与法定日相邻的工作日
  • 示例（2027 元旦）：法定 1/1–1/3（周五–周日）。请 12/28(一)–12/31(四) 共 4 天年假 → 连休 12/28–1/3 共 7 天。
  • 「不请假档」L=0，R=法定+相邻周末天数；卡片在无适配假期时显示「需请假 0 天（周末短途）」。
  • 需调班的周末计为工作日，若落在行程内须额外请假或避开，日历单独标识。
